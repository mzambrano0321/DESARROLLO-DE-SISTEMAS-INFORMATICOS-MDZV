#  Sistema de HelpDesk - API RESTful

Sistema de gestión de tickets de soporte técnico desarrollado con el stack MERN (MongoDB, Express, Node.js).

---

##  Tecnologías y Dependencias Utilizadas

* **Node.js**: Entorno de ejecución para JavaScript.
* **Express.js**: Framework backend para la creación de la API REST.
* **MongoDB & Mongoose**: Base de datos NoSQL y ODM para el modelado de datos de tickets.
* **dotenv**: Gestión de variables de entorno.
* **CORS**: Middleware para permitir peticiones entre frontend y backend.
* **BcryptJS & JSONWebToken**: Autenticación y seguridad.
